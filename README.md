## NebulaQuant

NebulaQuant is a Python project I created to analyse and compare historical stock-market data using `yfinance`, `pandas` and `Matplotlib`.

## Features

* Downloads data for user-selected stocks and time periods
* Cleans and normalises prices to a starting value of 100
* Plots multiple stocks for comparison
* Calculates percentage returns and volatility
* Ranks stocks by performance and risk
* Produces a correlation matrix of daily returns

## Files

* `graph.py` — price normalisation and visualisation
* `volatility.py` — return and volatility analysis
* `correlation_matrix.py` — correlation analysis

This project was created to develop my Python and data-analysis skills using real-world financial data.
